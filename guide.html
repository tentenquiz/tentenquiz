텐텐퀴즈 학습 안내

처음 시작하는 학습자를 위한 단계별 사용법

텐텐퀴즈는 10초 안에 단어의 뜻을 떠올리고, 틀린 문제는 다시 풀며, 기억하고 싶은 단어는 내 단어장으로 반복하는 학습 서비스입니다. 아래 안내를 순서대로 읽으면 스테이지와 주제 선택부터 기록 복구까지 모든 핵심 기능을 이해할 수 있습니다.

빠른 시작 학습 구성 퀴즈 방법 오답 복습 내 단어장 추천 학습 순서 기록 보관 자주 묻는 질문

1. 처음 시작하는 방법

  1. 나의 언어를 선택합니다.
    문제의 정답과 화면 안내에 사용할 언어입니다.
  2. 학습 언어를 선택합니다.
    새로 익히고 싶은 단어가 출제되는 언어입니다. 나의 언어와 같은 언어는 학습 언어 목록에서 제외됩니다.
  3. 스테이지를 선택합니다.
    스테이지 1의 친숙한 생활 어휘부터 시작하거나 자신의 수준에 맞는 단계를 고를 수 있습니다.
  4. 학습할 주제를 선택합니다.
    자연·날씨, 음식·음료, 학교·일처럼 현재 집중하고 싶은 생활 주제를 고릅니다.
  5. 10문제 퀴즈를 시작합니다.
    문제를 듣고 읽은 뒤, 10초 안에 네 개의 보기에서 알맞은 뜻을 선택합니다.

처음이라면 스테이지 1에서 관심 있는 주제 하나를 선택해 시작하세요. 한 번에 모든 단어를 외우기보다 10문제씩 짧게 풀고, 틀린 문제를 바로 복습하는 편이 텐텐퀴즈의 구조를 익히기 쉽습니다.

2. 스테이지와 주제는 어떻게 구성되나요?

전체 학습 자료는 10개 스테이지 × 10개 생활 주제 × 주제별 25개 어휘로 구성됩니다. 한 스테이지에는 250개, 전체에는 2,500개의 생활 어휘 개념이 들어 있습니다.

10개생활 주제
25개주제별 어휘

  • 🌿 자연 / 날씨
  • 👥 사람 / 관계
  • 🩺 몸 / 건강

  • 🏠 집 / 생활

  • 🚌 장소 / 교통
  • 📚 학교 / 일

  • 📅 시간 / 달력

스테이지와 주제의 차이

스테이지는 어휘의 학습 순서를 나타냅니다. 낮은 스테이지에서 익숙하고 쉽게 그려지는 생활 단어를 먼저 만나고, 단계가 올라갈수록 조금 덜 자주 쓰이지만 알아 두면 유용한 어휘로 넓어집니다.

주제는 어휘가 사용되는 생활 장면을 나타냅니다. 같은 스테이지 안에서는 여러 주제를 자유롭게 오가도 되며, 주제별 진행도는 각각 표시됩니다.

3. 10초·10문제 퀴즈는 어떻게 진행되나요?

한 회차에는 최대 10문제가 무작위 순서로 출제됩니다. 짧은 제한 시간은 번역을 한 글자씩 분석하기보다 단어와 뜻을 빠르게 연결하는 연습을 돕고, 10문제 단위는 부담 없이 다시 시작할 수 있게 합니다.

  • 문제 카드의 스피커를 누르면 학습 언어의 발음을 다시 들을 수 있습니다.
  • 정답을 고르면 다음 문제로 빠르게 넘어갑니다.
  • 오답을 고르거나 10초가 지나면 정답이 화면에 크게 나타납니다.
  • 일반 주제에서 틀리거나 시간이 지난 문제는 해당 스테이지의 ‘오답 클리어하기’에 저장됩니다.
  • 한 회차의 10문제를 모두 맞히면 100점 축하 효과가 화면을 이동할 때까지 이어집니다.

주제별 25개 어휘를 모두 풀면 해당 주제 버튼에 완료 상태가 표시되고 작은 축하 효과가 나타납니다. 이때 현재 학습 기록도 암호화되어 클라우드에 자동 저장됩니다.

4. 오답 클리어하기 사용법

오답 클리어하기는 단순히 틀린 답을 보여 주는 목록이 아니라, 같은 문제를 다시 풀어 기억을 확인하는 복습 공간입니다.

  1. 일반 주제에서 오답을 고르거나 시간이 지나면 문제가 자동으로 오답 목록에 들어갑니다.
  2. 현재 스테이지의 주제 선택 화면에서 ‘오답 클리어하기’를 누릅니다.
  3. 저장된 문제를 다시 풀고 정답을 맞히면 해당 문제가 오답 목록에서 제거됩니다.
  4. 아직 기억나지 않아 다시 틀린 문제는 목록에 남으므로 다음 복습에서 다시 만날 수 있습니다.

추천 방법: 새 주제를 여러 번 이어서 풀기 전에 오답 클리어하기의 숫자를 먼저 0으로 만들어 보세요. 틀린 직후의 짧은 복습과 다음 학습 때의 재도전을 함께 사용할 수 있습니다.

5. 내 단어장 사용법

내 단어장은 틀린 단어만 모으는 곳이 아닙니다. 정답을 맞혔더라도 다시 보고 싶은 단어를 결과 화면에서 직접 추가해 개인 복습 목록을 만들 수 있습니다.

  • 내 단어장에 들어 있는 문제는 학습자가 그만둘 때까지 순서를 바꾸어 계속 반복됩니다.
  • 오답을 선택하거나 시간이 지나면 기존 정답 표시 효과가 그대로 나타납니다.
  • 이때 화면 언어인 ‘나의 언어’로 정답 음성을 한 번 들려준 뒤 다음 문제로 자동 이동합니다.
  • 모국어 또는 학습 언어를 바꾸어도 각 언어 조합과 스테이지의 단어장 기록은 서로 섞이지 않습니다.

예를 들어 나의 언어가 일본어이고 학습 언어가 중국어라면, 중국어 문제를 틀렸을 때 정답 뜻을 일본어 음성으로 확인합니다. 학습 언어의 소리와 모국어 뜻을 연속해서 연결하려는 기능입니다.

6. 이렇게 반복해 보세요

  1. 새 어휘 10문제를 풉니다.
    처음부터 완벽하게 맞히려 하기보다 모르는 단어를 발견하는 시간으로 사용합니다.
  2. 오답 클리어하기로 바로 복습합니다.
    방금 틀린 단어를 다시 떠올려 정답으로 지웁니다.
  3. 중요한 단어는 내 단어장에 추가합니다.
    헷갈리는 단어, 발음을 더 듣고 싶은 단어, 꼭 기억하고 싶은 단어를 따로 모읍니다.
  4. 같은 주제의 25문제를 완료합니다.
    진행 표시와 작은 축하 효과로 한 학습 단위의 완료를 확인합니다.
  5. 다음 날 단어장을 짧게 반복합니다.
    이미 본 단어를 다시 만났을 때 뜻이 얼마나 빨리 떠오르는지 확인합니다.

학습량보다 중요한 것은 다시 돌아오는 습관입니다. 한 번에 긴 시간 공부하기 어렵다면 스테이지 하나를 끝내려 하지 말고, 10문제 한 회차와 오답 정리까지만 완료해도 좋습니다.

7. 학습 기록은 어디에 저장되나요?

언어 설정, 주제별 진행도, 오답과 내 단어장은 사용 중인 브라우저에 자동 저장됩니다. 회원가입이나 비밀번호 입력은 필요하지 않습니다.

주제별 25문제를 처음 완료하면 의미 있는 학습 성과를 보호하기 위해 클라우드에도 암호화 백업을 생성합니다. 학습 기록 관리 화면에서 복구 코드를 확인해 안전한 곳에 보관하면 다른 기기에서 기록을 불러올 수 있습니다.

  • 복구 코드는 학습 기록을 여는 열쇠이므로 다른 사람에게 알려 주지 마세요.
  • 기존 기기와 복구 코드를 모두 잃으면 운영자가 이메일이나 이름으로 기록을 찾아 줄 수 없습니다.
  • 공용 컴퓨터에서는 학습이 끝난 뒤 브라우저 기록과 복구 코드 관리에 특히 주의하세요.

저장 정보와 암호화 백업에 관한 자세한 설명은 개인정보처리방침에서 확인할 수 있습니다.

8. 자주 묻는 질문

같은 스테이지에서 여러 주제를 섞어 공부해도 되나요?

네. 같은 스테이지 안의 10개 주제는 원하는 순서로 학습할 수 있습니다. 각 주제의 25문제 진행도는 따로 계산되므로 학습 순서 때문에 기록이 섞이지 않습니다.

나의 언어나 학습 언어를 바꾸면 오답과 단어장이 섞이나요?

섞이지 않습니다. 학습 기록은 나의 언어, 학습 언어, 스테이지를 기준으로 구분합니다. 예를 들어 한국어로 영어를 학습한 단어장과 일본어로 영어를 학습한 단어장은 별도로 유지됩니다.

오답도 주제의 25문제 진행도에 포함되나요?

진행도는 해당 어휘를 풀어 보았는지를 표시합니다. 틀린 문제는 별도로 오답 클리어하기에 남으므로, 주제를 완료한 뒤에도 오답 목록을 0으로 만드는 복습을 권합니다.

소리가 들리지 않으면 어떻게 하나요?

기기의 미디어 음량과 브라우저의 사이트 음소거 여부를 먼저 확인하세요. 일부 브라우저는 첫 음성 재생 전에 화면을 한 번 눌러야 할 수 있습니다. 그래도 특정 단어만 들리지 않거나 발음이 어색하다면 단어와 선택한 언어를 적어 문의해 주세요.

앱처럼 바탕화면이나 휴대폰 홈 화면에서 열 수 있나요?

지원되는 브라우저에서는 화면 상단의 설치 안내를 눌러 텐텐퀴즈를 설치할 수 있습니다. 설치 후에는 브라우저 주소를 다시 입력하지 않고 바탕화면 바로가기 또는 휴대폰 아이콘으로 실행할 수 있습니다.

9. 도움이 더 필요한가요?

특정 언어의 표기나 발음 문제, 기록 불러오기 오류, 화면 사용의 불편함을 발견하면 문의·도움말을 확인한 뒤 아래 이메일로 알려 주세요. 문제를 재현할 수 있도록 사용 기기, 브라우저, 나의 언어와 학습 언어를 함께 적어 주시면 확인에 도움이 됩니다.
